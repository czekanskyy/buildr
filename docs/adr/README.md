# Architecture Decision Records

Each ADR follows the same template: **Status, Context, Options, Decision, Consequences**. ADRs are immutable once `Accepted`; a reversed decision gets a new ADR that supersedes the old one (the old one's Status is updated to `Superseded by ADR-0xx`).
