# @next-buildr/next

## 1.0.0

### Minor Changes

- ba0a618: `@next-buildr/next/canvas`: `BuildrCanvasPage` (authorized, dynamic, noindex), `canvasMetadata` and `buildrSecurityHeaders()` for `next.config`.
- 73a3757: `@next-buildr/next/draft`: `createPreviewRoute`, `createExitPreviewRoute`, `safeRedirectPath` (relative redirects only) and `PreviewBanner`.
- 7597e43: `@next-buildr/next/editor`: `BuildrEditorPage` (dynamic, login redirect, server-computed manifest, serializable client props) and `editorMetadata`.
- 94fa000: Locale routing: `isLocale`, `negotiateLocale`, `createLocaleMiddleware`, `generateLocaleStaticParams`, `x-default` in hreflang (`defaultLocale`) and a `locales` option on the preview route.
- 1aefd58: `BuildrPage`, `createBuildrConfig`, `createNextPlatform`, `BuildrSectionBoundary` and `buildrMetadata`: production rendering under the App Router.
- 9504f2a: The 0.1.0 MVP release: the document model, the renderer, the standard components and templates, the visual editor, and the Next.js and Payload integrations, with the reference application and its end-to-end tests.

### Patch Changes

- 9cdc2ac: `HeaderRule` is assignable to Next's `Header` (`headers()` in next.config).
- 1ba33ad: Rename the npm scope from @buildr to @next-buildr
