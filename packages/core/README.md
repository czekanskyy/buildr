# @next-buildr/core

Framework-independent document model and building blocks for Buildr: schemas, values, expressions, styles, validation, migrations, and commands.

Install with `npm install @next-buildr/core`. Import the main API from `@next-buildr/core`; document edits go through `@next-buildr/core/commands`.

Source and guides: [Buildr repository](https://github.com/czekanskyy/buildr).
