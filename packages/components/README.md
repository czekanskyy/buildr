# @next-buildr/components

Ready-made, accessible page components, templates, and theme styles for Buildr, built on `@next-buildr/react`.

Install with `npm install @next-buildr/components @next-buildr/react @next-buildr/core react react-dom`. Import `@next-buildr/components/styles.css` to use the bundled styles. See the [Buildr repository](https://github.com/czekanskyy/buildr).
