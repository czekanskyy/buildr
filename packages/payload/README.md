# @next-buildr/payload

Payload CMS integration for Buildr, including the plugin, data source, admin field, adapter, Next.js helpers, and optional MCP route.

Install with `npm install @next-buildr/payload @next-buildr/core payload`. Import the entry point that matches your integration, such as `@next-buildr/payload/plugin` or `@next-buildr/payload/adapter`. See the [Buildr repository](https://github.com/czekanskyy/buildr).
