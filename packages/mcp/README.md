# @next-buildr/mcp

Model Context Protocol server and command-line client for reading and editing Buildr documents through the Buildr command API.

Install with `npm install @next-buildr/mcp`. Run the `buildr-mcp` command to start the CLI, or import the server API from `@next-buildr/mcp`. See the [Buildr repository](https://github.com/czekanskyy/buildr) for configuration.
