# @next-buildr/editor

Embeddable visual editor for Buildr documents. The editor connects to a Buildr canvas through the versioned canvas protocol.

Install with `npm install @next-buildr/editor @next-buildr/core react react-dom`. Import `@next-buildr/editor/styles.css` in your application. See the [Buildr repository](https://github.com/czekanskyy/buildr) for integration guidance.
