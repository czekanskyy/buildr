Style inspector and value editor controls (PB-128): a box-model widget for margin and padding, `NumberUnitInput` with arrow-key steps and a grammar-limited unit menu, theme token pickers with colour swatches, icon segmented controls for direction, alignment, justify and text-align, an origin dot per style property, and the Fixed / Data / Formula switch as a segmented control with icons. Every control writes the same `node.setStyle` / `node.setProp` commands as before.
