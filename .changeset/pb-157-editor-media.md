The media control accepts a link to an external file as well as a library file. A valid https address opens the "Zewnętrzne źródło" warning (ADR-028) and is stored as `{ external: true, url }` only after "Potwierdzam i dodaję link"; Cancel stores nothing. The `url` of `buildr/iframe` uses the same warning. The inspector groups a container's background and overlay props under "Tło" and shows fit, scrolling and overlay tone as segments. Wideo and Iframe get Polish labels and descriptions. No document or prop shape changed.
